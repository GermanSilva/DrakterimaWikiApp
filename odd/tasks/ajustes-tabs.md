# Ajustes in tabs with a sticky save bar

Turn the campaign Ajustes page (13 stacked blocks, ~7000 px of scroll) into horizontal tabs with one sticky save bar per tab.
Visual spec: design/ajustes-tabs/01-barra-de-guardado-fija.html (chosen artboard; 02 and 03 are alternatives). Tokens: design/system.md.
Branch: feat/campaign-hub. Status: implemented (T1-T5 done).

## Specs

- S1 (L1): "Creo que lo mejor sería que los ajustes se dividan en tabs (listados horizontalmente), para que sea más rápido acceder a las distintas secciones de ajuste, y que algunos botones como el de "guardar plantilla" de plantilla de ficha, puedan ser rapidamente accesibles o puedan permanecer fijos."
  Tabs (artboard): Campaña (Identidad y marca, Regiones), Sistema (Datos del sistema, Unidades de distancia, Economía, Homebrew), Ficha (Plantilla de ficha, Campos de personaje), Juegos (Lotería, Pozo acumulado, Registro de tiradas), Jugadores (Miembros, Dueños de personajes, Invitaciones), Datos (Exportar, Zona de peligro). ARIA tablist with arrow/Home/End keys; the tab is in the URL (`?tab=ficha`, invalid values fall back to Campaña); switching tabs keeps unsaved edits; narrow screens scroll the tabs with chevrons (ScrollStrip).
- S2 (L2, comment zf73yxoi): "Habría que quitar ya este apartado en ajustes ya que la sesión en vivo ya tiene su acceso directo en el sidebar, una alternativa mucho más directa y accesible" (remove the "Pantalla de sesión" block from Ajustes).
- S3 (L3, decision): "Un guardar por pestaña": the sticky bar at the bottom saves together every modified block of the active tab and warns about other tabs with unsaved changes ("También sin guardar: …", each a link to that tab). If a block fails, the bar says which one and the others stay saved. The bar shows "<Tab> · N cambios sin guardar" (or "Sin cambios"), "Descartar" and "Guardar <…>"; with template errors it shows "· N errores impiden guardar" and the save button is disabled with that reason. A tab with unsaved changes shows a red dot; a template with errors shows "Error" on the Ficha tab. Tabs whose blocks act immediately (Jugadores, Datos, the pot transfer, the roll log) have no bar. The bar appears only when the tab has changes, except Ficha where it is always visible.
- S4 (L4, comment t45djsz9 + 9wddl7ru): "Los niveles no deberían estar limitados sólo hasta el 20. Puede haber otros sistemas con muchos más niveles numéricos." / "Colocar el checkbox (+label) y los inputs de rango en la misma linea." Hint: "Cualquier rango entre 0 y 1000; por ejemplo 1 a 100 para sistemas con progresión larga."
- S5 (L5, comment 1g249cr6): "Cambiar texto a "Usar «Clase/Trabajo/Grupo»", y Agregar un campo que permita ingresar el título a utilizar (en caso de que se habilite la opción)". Hint: "Cómo se llama en tu sistema: Clase, Trabajo, Oficio, Grupo… Se usa en la ficha, la lista y el buscador." The title input is disabled while the option is off.
- S6 (L6, comment 2u87xahk): "Cambiar texto a "Usar «Raza/Especie»", y agregar campo de texto para título." Hint: "Cómo se llama en tu sistema: Raza, Especie, Linaje, Ascendencia… Se usa en la ficha, la lista y el buscador."
- S7 (L7, comment ro24oz08 + decision): "Basado en" is READ-ONLY ("Solo lectura"): it shows the real lineage (campaigns.based_on_system -> system name) and "Sistema original (no se basa en ninguno)" when there is none. Hint: "Solo informativo: la campaña tiene su propia copia y no recibe cambios del sistema elegido."
- S8 (L8, comments ro2camiz + h9icudmb + decision): "En esta pestaña debería estar la configuración de Economía" / "Aquí se deberían configurar las instancias de economía, pudiendo crear, editar, y eliminar. Como el destino de recompensa afecta directamente la configuración de los juegos, debería estar en la pestaña Juegos" / "Sería solo en Sistema/Juegos. El builder de ficha sólo debería configurar cómo y en qué parte de la ficha/tarjeta mostrarlo."
  Sistema › Economía: denominations (clave, moneda, equivalencia a la base, "+ Agregar moneda", summary "1 oro = 10 plata = 100 bronce") and economy instances (create, edit, delete; delete disabled for the reward destination with the reason "Es el destino de recompensa: elegí otro en Juegos antes de eliminarla"; deleting an instance with stored amounts follows the discarded-fields rule, "la pasa a campos descartados por 60 días"). Juegos › Lotería: "Destino de recompensa" select (instances + "Ninguno"), hint "Donde se acreditan la lotería, el pozo y las recompensas. Las instancias se crean en Sistema › Economía. Sin destino, la lotería no aparece en Juegos." with a link to Sistema › Economía. The sheet builder no longer edits denominations, instances' existence or the reward destination; it only places/displays them (section, block, card).
- S9 (L9, comment 9vahp0rg): "Permitir colapsar esta sección para mayor control del espacio." (the builder's "Vista previa" pane collapses to a narrow rail with a vertical label; the button has aria-expanded; collapsed content is hidden; the editors take the width).
